# 🌤️ ClimaTempo

Aplicação de previsão do tempo desenvolvida com **HTML, CSS e JavaScript**, utilizando a API **Open-Meteo** para consultar dados meteorológicos em tempo real.

## 🚀 Funcionalidades

- 🔎 Pesquisa de cidades
- 🌡️ Temperatura atual
- 🌤️ Condição climática atual
- 🌡️ Temperatura máxima e mínima
- 💧 Umidade do ar
- 💨 Velocidade do vento
- 📅 Previsão para os próximos dias
- 🌍 Suporte a cidades de diferentes países
- ⚠️ Tratamento de cidades não encontradas
- 📱 Interface responsiva

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API

## ▶️ Como executar

Não é necessário instalar nenhuma dependência.

Basta baixar ou clonar o projeto e abrir o arquivo:

```text
index.html
```

em um navegador.

Também é possível publicar o projeto utilizando o **GitHub Pages**.

## 🌐 API

O projeto utiliza a **Open-Meteo** para obter os dados meteorológicos.

A aplicação utiliza dois serviços:

- **Geocoding API** — utilizada para encontrar a localização da cidade pesquisada.
- **Weather API** — utilizada para obter as informações meteorológicas.

## 🎯 Objetivo

Projeto desenvolvido para praticar conceitos de desenvolvimento web, principalmente:

- Consumo de APIs
- Utilização do `fetch()`
- Programação assíncrona com `async/await`
- Manipulação do DOM
- Eventos em JavaScript
- Tratamento de erros
- Responsividade com CSS

## 📱 Responsividade

A interface foi desenvolvida para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.
